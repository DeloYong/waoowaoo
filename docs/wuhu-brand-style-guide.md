## 一、品牌核心定位

### 1.1 品牌基础信息

| 项目 | 内容 |
|------|------|
| **中文名** | 芜湖 |
| **英文名** | wuhu |
| **核心口号** | 芜湖起飞！AI 创作，惊喜连连 |
| **品牌精神** | 娱乐性、趣味性、惊喜感、创造力 |
| **品牌气质** | 酷萌风、霓虹活力、搞怪有趣 |

### 1.2 品牌故事

Wuhu 品牌的核心是**「惊喜感」**——就像看到视频成品时脱口而出的那句「芜湖起飞！」。

呜虎小怪兽的形象代表了创意的精灵，霓虹色彩象征着灵感的火花。每一次创作，都是一场惊喜的旅程。

### 1.3 目标用户

- 短剧/漫画视频创作者
- 年轻内容创作者
- 追求趣味和效率的 AI 工具使用者

## 二、视觉识别系统

### 2.1 色彩系统

#### 霓虹三原色（核心）

```css
/* 电光紫 - 主色/品牌色 */
--wuhu-neon-purple: oklch(0.65 0.28 290);  /* #A757FF */

/* 荧光粉 - 强调/交互 */
--wuhu-neon-pink: oklch(0.7 0.32 350);     /* #FF64C8 */

/* 亮青色 - 高亮/成功 */
--wuhu-neon-cyan: oklch(0.75 0.25 180);    /* #64FFFF */
```

#### 背景色

```css
/* 深紫黑 - 页面背景 */
--wuhu-bg-dark: oklch(0.15 0.05 280);     

/* 深底色 - 卡片背景 */
--wuhu-bg-surface: oklch(0.2 0.05 280);   
```

#### 渐变系统

```css
/* 主渐变 - 霓虹流动（紫→粉→青） */
--wuhu-gradient-primary: linear-gradient(
  135deg, 
  var(--wuhu-neon-purple), 
  var(--wuhu-neon-pink), 
  var(--wuhu-neon-cyan)
);

/* 按钮渐变（紫→粉） */
--wuhu-gradient-btn: linear-gradient(
  135deg, 
  var(--wuhu-neon-purple), 
  var(--wuhu-neon-pink)
);

/* 文字渐变（青→紫→粉） */
--wuhu-gradient-text: linear-gradient(
  90deg, 
  var(--wuhu-neon-cyan), 
  var(--wuhu-neon-purple), 
  var(--wuhu-neon-pink)
);
```

#### 色彩使用原则

- **深色背景优先**：所有设计统一深紫黑背景，确保霓虹效果最佳呈现
- **发光一致性**：所有边框、分割线、按钮都使用渐变发光效果
- **视觉焦点**：每页不超过 3 个核心视觉元素，保持精简

### 2.2 Logo 设计规范

#### 文字 Logo 核心特征

| 特征 | 描述 |
|------|------|
| **字体** | 圆润无衬线字体，字母边缘做圆角处理 |
| **效果** | 霓虹发光外发光效果 |
| **"w" 字母** | 做波浪形处理，像起飞的翅膀 |
| **"u" 字母** | 内部融入小怪兽眼睛元素 |
| **发光层次** | 内层 `0 0 20px rgba(167, 87, 255, 0.8)`，外层 `0 0 40px rgba(255, 100, 200, 0.4)` |

#### Logo 变体

| 变体 | 用途 | 说明 |
|------|------|------|
| **完整版本** | wuhu | 主要场景使用 |
| **简化版本** | WH | 小尺寸场景 |
| **图标版本** | 仅发光的 W 字母 | App 图标、favicon |

#### Logo 使用规范

- 最小使用尺寸: 32px
- 安全边距: Logo 周围保留至少 20% 的空白区域
- 背景: 优先使用深色背景以突出霓虹效果

## 三、吉祥物「呜虎 (Woohoo)」设计规范

### 3.1 核心形象

| 属性 | 描述 |
|------|------|
| **名字** | 呜虎 (Woohoo) |
| **类型** | 圆滚滚的创意小怪兽 |
| **体型** | 球形身体，宽:高 = 1:1.2 |
| **核心特征** | 半透明身体 + 霓虹尖角 + 星星眼 |
| **性格** | 搞怪、好奇、充满创造力、喜欢恶作剧但善良 |

### 3.2 形象细节规范

#### 身体结构

```
┌─────────────────────────────┐
│         ╱◥◤╲  ← 两个尖角     │
│        ╱     ╲   带霓虹发光   │
│       │  ◙   ◙ │  ← 大眼睛    │
│       │   ⌒   │  ← 嘴巴       │
│       │       │               │
│        ╲─────╱    半透明球形  │
│         ●   ●     小爪子       │
└─────────────────────────────┘
```

#### 具体参数

| 部位 | 详细描述 |
|------|----------|
| **身体** | 圆球形主体，半透明质感，内部有能量流动效果，渐变色填充（紫→粉） |
| **眼睛** | 大大的圆形眼睛，瞳孔带星芒高光，会眨眼；左眼紫色系，右眼粉色系 |
| **角** | 头顶两个小尖角，带霓虹发光效果；左角紫色，右角粉色 |
| **爪子** | 小小的、肉肉的爪子，半透明白色 |
| **内部效果** | 身体内部有多层同心椭圆的能量流动线条（青色+粉色） |
| **外发光** | 整个形象带柔和的霓虹外发光效果 |

### 3.3 6 个核心表情系统

#### 😜 眨眼（默认）
- **用途**: 日常默认状态，亲和力强
- **特征**: 左眼眨眼（变成弧线），右眼正常，嘴角微微上扬，舌头微微伸出
- **感觉**: 搞怪、俏皮、友好

#### ⭐ 惊喜
- **用途**: 生成完成、获得好结果
- **特征**: 双眼变成大星星（瞳孔是★形状），嘴巴变成大 O 型
- **感觉**: 惊叹、惊喜、 wow

#### 🎬 导演
- **用途**: 创作中、工作状态
- **特征**: 戴导演帽（黑色+霓虹边框），眼神专注，嘴角自信微笑
- **感觉**: 专业、可靠、在创作

#### 🎉 庆祝
- **用途**: 成功、完成任务
- **特征**: 眼睛弯弯笑成月牙，周围有彩色撒花粒子（粉+青+紫）
- **感觉**: 开心、庆祝、胜利

#### 🤔 思考
- **用途**: 生成中、加载、思考问题
- **特征**: 眼神向上看（思考状），嘴巴微嘟，头顶有问号灯泡
- **感觉**: 思考中、创意迸发、稍等

#### 🥺 抱歉
- **用途**: 错误、失败、需要重试
- **特征**: 眼睛弯成委屈的弧线，嘴角下撇，挠头姿势
- **感觉**: 抱歉、小失误、求原谅

### 3.4 吉祥物使用场景

| 场景 | 推荐表情 | 姿势 |
|------|----------|------|
| **空状态** | 🥺 抱歉 | 摊手，表示"这里还没有内容哦" |
| **加载中** | 🤔 思考 | 旋转/跳舞，带霓虹拖尾 |
| **成功提示** | 🎉 庆祝 | 比耶 + 烟花效果 |
| **错误状态** | 🥺 抱歉 | 挠头，表示"出了点小问题" |
| **引导教学** | 😜 眨眼 | 用手指指向操作区域 |
| **社交媒体** | 全部表情 | 表情包贴纸系列 |

## 四、界面设计风格

### 4.1 玻璃态 + 霓虹系统

#### 发光卡片

```css
.glow-card {
  background: var(--wuhu-bg-surface);
  border: 1px solid rgba(167, 87, 255, 0.3);
  border-radius: 16px;
  box-shadow: 
    0 4px 24px rgba(0, 0, 0, 0.3),
    0 0 0 1px rgba(167, 87, 255, 0.1) inset;
}

.glow-card:hover {
  box-shadow: 
    0 8px 32px rgba(0, 0, 0, 0.4),
    0 0 20px rgba(167, 87, 255, 0.2),
    0 0 0 1px rgba(255, 100, 200, 0.2) inset;
  transform: translateY(-2px);
}
```

#### 霓虹按钮

```css
.wuhu-btn-neon {
  border: 2px solid var(--wuhu-neon-purple);
  box-shadow: 
    0 0 10px var(--wuhu-neon-purple),
    inset 0 0 10px rgba(var(--wuhu-neon-purple), 0.1);
}
```

### 4.2 动画系统

#### 霓虹呼吸动画

```css
@keyframes neon-pulse {
  0%, 100% { 
    box-shadow: 0 0 15px var(--wuhu-neon-purple), 0 0 30px rgba(167, 87, 255, 0.3);
  }
  50% { 
    box-shadow: 0 0 25px var(--wuhu-neon-pink), 0 0 50px rgba(255, 100, 200, 0.2);
  }
}
```

#### 吉祥物漂浮动画

```css
@keyframes mascot-float {
  0%, 100% { transform: translateY(0) rotate(-3deg); }
  50% { transform: translateY(-15px) rotate(3deg); }
}
```

#### 粒子背景效果

- 小圆点粒子，缓慢漂浮
- 颜色：霓虹色系（紫/粉/青）
- 带轻微发光效果
- 动画时长 6-8 秒循环

## 五、设计关键词与风格参考

### 5.1 风格关键词

| 维度 | 关键词 |
|------|--------|
| **整体风格** | 赛博朋克、霓虹、酷萌、未来感 |
| **色彩** | 高饱和度撞色、紫粉青三色、深色背景 |
| **质感** | 半透明、玻璃态、发光、渐变 |
| **性格** | 搞怪、俏皮、惊喜、创意、活力 |
| **形状** | 圆润、球形、圆角、无尖锐棱角 |

### 5.2 对比参考

- ❌ 不是：可爱到幼稚的日式 Q 版
- ❌ 不是：硬核赛博朋克（过于冷硬）
- ✅ 是：**酷萌** = 酷炫霓虹 + 萌系圆润
- ✅ 是：像随时会跳出来给你惊喜的小恶魔

### 5.3 设计原则总结

1. **圆润优先**：所有角都做圆角处理
2. **发光必加**：所有重要元素都有霓虹外发光
3. **三色渐变**：紫→粉→青是核心流动渐变
4. **深色衬托**：永远用深背景突出霓虹效果
5. **惊喜感**：设计要让人看到就想说「芜湖！」

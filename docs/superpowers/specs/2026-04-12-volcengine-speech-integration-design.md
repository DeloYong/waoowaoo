## 一、需求背景
### 1.1 需求概述
在现有阿里云百炼语音能力的基础上，新增火山引擎作为可选语音提供商，所有前台语音功能都支持双提供商切换，原有阿里云功能完全保留。
### 1.2 功能范围
覆盖三类语音相关能力：
- ✅ 语音合成(TTS)：文本转语音，支持多音色、语速/音调调整
- ✅ 音色设计：自定义音色克隆、管理、预览
- ✅ 口型同步：音频驱动视频口型匹配
## 二、整体架构设计
### 2.1 架构原则
1. **最小侵入**：不修改原有阿里云相关代码和业务逻辑
2. **接口统一**：新增的火山实现完全适配现有语音接口规范，上层业务无感知
3. **平滑切换**：用户可以在任意场景自由切换提供商，原有数据完全保留
### 2.2 模块划分
```
┌─────────────────┐     ┌─────────────────┐
│  前台应用层      │────►│  业务逻辑层      │
│  (配音/音色等)   │     │                 │
└─────────────────┘     └─────────────────┘
          ▲                       ▲
          │                       │
          ▼                       ▼
┌─────────────────┐     ┌─────────────────┐
│  提供商适配层    │     │  后台配置层      │
│  ├─阿里云百炼    │     │  ├─模型预设      │
│  └─火山引擎      │     │  └─全局配置      │
└─────────────────┘     └─────────────────┘
```
## 三、详细设计
### 3.1 后台配置层
#### 3.1.1 新增预设模型
在`src/lib/admin-model-config.ts`中新增火山语音相关预设模型：
| 模型名称 | 模型ID | 类型 | 定价 |
|--------|-------|-----|-----|
| 豆包TTS标准版 | doubao-tts-v1 | audio | 0.01元/千字 |
| 豆包TTS精品版 | doubao-tts-premium-v1 | audio | 0.03元/千字 |
| 豆包长文本TTS | doubao-tts-long-v1 | audio | 0.015元/千字 |
| 豆包音色克隆 | doubao-voice-clone-v1 | voice-design | 1元/次 |
| 豆包口型同步 | doubao-lipsync-v1 | lipsync | 0.05元/分钟 |
#### 3.1.2 全局扩展配置适配
在平台API配置页面的扩展功能下拉选项中新增对应选项：
- 口型同步：新增「Doubao Lip Sync (火山引擎)」
- 语音合成：新增「Doubao TTS (火山引擎)」
- 音色设计：新增「Doubao Voice Design (火山引擎)」
原有阿里云选项完全保留。
### 3.2 核心逻辑层
#### 3.2.1 生成器实现
在`src/lib/generators/`下新增对应实现：
1. **火山TTS生成器**：
   - 继承`BaseAudioGenerator`
   - 支持参数：文本、音色ID、语速、音调、音量、音频格式
   - 适配火山API签名和请求规范
2. **火山音色设计生成器**：
   - 支持音频上传克隆、音色预览、删除管理
   - 适配火山音色生命周期管理接口
3. **火山口型同步生成器**：
   - 支持输入音频+基准视频/图片，生成口型匹配的视频
   - 适配异步任务查询接口
#### 3.2.2 接口适配
所有生成器完全适配现有统一接口：
```typescript
interface SpeechGenerator {
  generate(params: SpeechGenerateParams): Promise<GenerateResult>
  getVoiceList(): Promise<VoiceInfo[]>
  // 其他通用方法
}
```
和阿里云的调用接口完全一致，上层业务不需要修改。
#### 3.2.3 计费适配
在`src/lib/credit-billing/catalog.ts`中配置火山语音模型的计费规则：
- TTS按字数计费
- 音色克隆按次计费
- 口型同步按视频时长计费
完全适配现有积分扣除流程。
### 3.3 前台应用层
#### 3.3.1 提供商切换支持
所有语音相关功能页面新增提供商选择下拉：
- 角色配音页：可以选择用阿里云还是火山引擎合成
- 音色管理页：创建新音色时可以选择克隆到哪个提供商
- 视频生成页：语音驱动口型时可以选择提供商
默认选中后台配置的全局默认提供商。
#### 3.3.2 参数自动适配
根据选择的提供商动态显示对应支持的参数：
- 选择火山时：显示火山支持的音色列表、情绪/风格选项
- 选择阿里云时：显示阿里云的音色和参数
自动适配不同提供商的参数要求。
#### 3.3.3 数据兼容
- 原有阿里云的音色、配音项目完全保留，正常使用
- 新建内容会标记对应提供商，互不影响

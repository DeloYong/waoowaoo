# Wuhu 充值页面品牌风格重设计

**日期**: 2025-05-12
**状态**: 设计中
**版本**: v1.0

---

## 一、设计目标

将充值页面从旧的 "glass" 设计风格升级为新的 Wuhu 霓虹赛博朋克可爱风格，与整体品牌视觉系统保持一致，提升用户付费意愿和品牌认同感。

### 核心设计原则
1. **品牌一致性** - 全面应用 Wuhu 品牌色彩系统
2. **视觉吸引力** - 通过霓虹发光效果增强付费按钮的点击欲望
3. **吉祥物融入** - 在关键节点加入呜虎形象，增加亲和力
4. **动效增强** - 平滑过渡动画提升用户体验
5. **无障碍** - 确保色彩对比度符合可访问性标准

**设计变更**：

**设计变更**：
- 使用 WuhuCard 组件作为容器
- 状态标签：彩色发光效果（成功-绿色/待付-黄色/失败-红色）
- 空状态：集成 WuhuEmptyState 组件（thinking 表情）

## 三、具体技术实现规范

### 3.1 组件集成清单

| 组件 | 使用位置 | 配置 |
|------|---------|------|
| `WuhuMascot` | 顶部欢迎区、空状态 | `expression="happy"` / `"thinking"` |
| `WuhuCard` | 套餐卡片、订单摘要、历史记录 | `glow="purple"` / `"pink"` |
| `WuhuButton` | 主支付按钮 | `variant="gradient"`, `glow={true}` |
| `WuhuEmptyState` | 无套餐、无历史记录 | 自定义文案 |
| 霓虹文字渐变 | 余额数字、应付金额 | CSS `.wuhu-text-gradient` |

### 3.2 交互规范

1. **套餐选择**：
   - 点击卡片：`scale(1.02)` + 边框发光增强
   - 动画时长：200ms ease-out

2. **支付按钮**：
   - Hover：亮度 +10% + 外发光范围扩大
   - Click：缩放 0.98 + 霓虹脉冲动画
   - Loading：按钮内显示小吉祥物旋转动画

3. **支付成功**：
   - 弹出呜虎庆祝动画（surprised → happy 表情切换）
   - 彩虹光芒庆祝动效
   - 积分数字滚动增加动画

### 3.3 CSS 类名扩展

在现有 globals.css 基础上新增：

```css
/* 霓虹数字显示 */
.wuhu-neon-number {
  background: var(--wuhu-gradient-text);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  text-shadow: 0 0 20px rgba(167, 87, 255, 0.5);
}

/* 热门标签发光 */
.wuhu-tag-popular {
  background: linear-gradient(135deg, #f97316, #ef4444);
  box-shadow: 0 0 15px rgba(249, 115, 22, 0.5);
}

/* 选中套餐脉冲动画 */
.wuhu-package-selected {
  animation: wuhu-neon-pulse 2s ease-in-out infinite;
}
```

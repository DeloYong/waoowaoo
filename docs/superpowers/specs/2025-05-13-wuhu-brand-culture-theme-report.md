# Wuhu 品牌文化与主题设计报告

**日期**: 2026-05-13  
**版本**: v1.0  
**类型**: 对外品牌展示/营销版  
**风格**: 霓虹赛博视觉冲击版（精简版 3-5 页）

---

## 一、报告整体架构

### 1.1 文档定位

**目标受众**: 外部用户、潜在合作伙伴、营销传播渠道  
**核心目的**: 展示 Wuhu 品牌的独特魅力，建立品牌认知和喜爱度  
**传播渠道**: 官网、社交媒体、品牌手册、合作洽谈

### 1.2 视觉基调

- **主风格**: 霓虹赛博朋克 + 酷萌可爱
- **背景色**: 统一深紫黑色渐变，突出霓虹发光效果
- **色彩系统**: 高饱和度三原色撞色
- **视觉原则**: 每页不超过 3 个核心视觉元素，精简有力

```

│                                                 │
│                      🐉                         │  ← 呜虎主形象（跳跃姿态）
│                                                 │
│           芜湖起飞！AI 创作，惊喜连连            │  ← Slogan
│                                                 │
└─────────────────────────────────────────────────┘
```

**设计细节**：
- **背景**: `linear-gradient(135deg, oklch(0.12 0.05 280) 0%, oklch(0.15 0.04 300) 100%)` + 细微粒子漂浮效果
- **Logo 文字**:
  - 字体：圆润无衬线字体
  - "w" 做波浪形处理，"u" 内部融入小怪兽眼睛元素
  - 文字填充：三色渐变 `var(--wuhu-gradient-text)`
  - 发光效果：内层 `0 0 20px rgba(167, 87, 255, 0.8)`，外层 `0 0 40px rgba(255, 100, 200, 0.4)`
- **呜虎位置**: 右下区域，呈 15° 跳跃角度，身体带霓虹粒子拖尾
- **Slogan**: 底部居中，渐变色文字，字号适中

```
│                      │  │  ┌─────────┬─────────┬─────────┐

│     主形象           │  │  ├─────────┼─────────┼─────────┤

│                      │  │  └─────────┴─────────┴─────────┘
│  名字: Woohoo        │  │                              │
│  类型: 圆滚滚小怪兽   │  │                              │
└──────────────────────┘  └──────────────────────────────┘
```

**呜虎形象规范**：

| 属性 | 描述 |
|------|------|
| **体型** | 圆球形，宽:高 = 1:1.2 |
| **眼睛** | 大大圆形，瞳孔带星芒高光，会眨眼 |
| **角** | 头顶两个小尖角，带霓虹发光效果 |
| **身体** | 半透明质感，内部有能量流动效果 |
| **爪子** | 小小的、肉肉的 |
| **默认表情** | 眨眼搞怪笑，舌头微微伸出 |

**6 个核心表情**：
1. 😜 **眨眼** — 日常默认，亲和力强
2. ⭐ **惊喜** — 眼睛变星星，嘴巴 O 型
3. 🎬 **导演** — 戴导演帽，手持场记板
4. 🎉 **庆祝** — 撒花，身上有烟花特效
5. 🤔 **思考** — 摸下巴，头顶有问号灯泡
6. 🥺 **抱歉** — 挠头，委屈小表情

**每个表情都带同色系霓虹外发光**

## 三、设计规范与一致性

### 3.1 统一设计原则

1. **深色背景优先**：所有页面统一深紫黑背景，确保霓虹效果最佳呈现
2. **发光一致性**：所有边框、分割线、按钮都使用渐变发光效果
3. **吉祥物贯穿**：每页至少有一处呜虎元素（可以是隐藏的彩蛋）
4. **视觉焦点**：每页不超过 3 个核心视觉元素，保持精简
5. **动画呼吸感**：所有发光元素都带轻微的呼吸动画效果

### 3.2 色彩使用规范

| 用途 | 颜色 | 备注 |
|------|------|------|
| 背景 | `oklch(0.12-0.15 0.04-0.05 280-300)` | 统一深色系 |
| 主标题 | 三色渐变文字 | 重要标题 |
| 副标题 | 白色 `rgba(255,255,255,0.9)` | 清晰可读 |
| 正文 | 白色 `rgba(255,255,255,0.7)` | 舒适阅读 |
| 辅助文字 | 白色 `rgba(255,255,255,0.5)` | 弱化层次 |
| 强调色 | 荧光粉 `var(--wuhu-neon-pink)` | 交互、重点 |

### 3.3 排版层级

| 层级 | 字号 (pt) | 字重 | 用途 |
|------|-----------|------|------|
| H1 | 72 | Bold | 封面大标题 |
| H2 | 36 | Semibold | 页面标题 |
| H3 | 24 | Medium | 栏目标题 |
| Body | 16 | Regular | 正文内容 |
| Small | 12 | Regular | 辅助说明 |
